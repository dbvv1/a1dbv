# 会话交接

更新（或创建）项目根目录的 `PROGRESS.md`，**覆盖旧内容，只保留当前状态**：

```markdown
# 进度（更新于 <日期时间>）

## 目标
<一两句话，链接到 SPEC.md / Issue（如果有）>

## 已完成
- <做了什么> —— 证据：<提交哈希 / 测试命令和结果>

## 进行中
- <正在做什么，做到哪一步>

## 关键决策与原因
- <决策> —— <为什么；放弃了哪些方案>

## 已知问题和坑
- <新会话最容易再踩的坑>

## 下一步（按顺序）
1. ...

## 常用命令
- 构建 / 测试：`...`
```

要求：
- 只写**新会话需要、而且从代码和 git log 里看不出来**的信息。
- 已完成的项目必须附证据；没有验证过的写进“进行中”。
- 写完后告诉用户：可以 `/clear` 或开新会话，然后说“读 PROGRESS.md 继续”。
