- BAML 与后续计划评审共用“判据与反馈能否推翻计划”的机制；研究位置选择、原意遗漏、接缝遗漏和过期接口分别说明
- 上下文研究共用“怎样解释额外指令的收益”；两项研究的样本、模型、过滤和统计口径仍完全分开
- Handy 的实际受益与采用取舍、Immich 的接收修订、oMLX 的合入后能力探针，以及 alchemy/VibeTunnel 的数据语义/所有权分别保留，不因同属主线就强行拼成案例大全
- 原研究战略没有独立新证据，其有用原则并入本页；方向不再反复写成新的研究产物
