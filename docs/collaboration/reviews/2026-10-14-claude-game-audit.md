## 3. 需要修正或补充的地方

云端已提出的 F1（Unity / Unreal 入口和 CLAUDE 模板仍默认要求 MCP）、F2（03 授权表断裂）继续有效，下面不重复。

1. **Unity 官方 AI 生成器覆盖不足（重要）**：Unity 6 自带 AI 生成功能（精灵、贴图、动画、音效等），对“Unity 优先、单人程序”的场景是最直接的候选，但相关内容全仓只出现 6 次，也没有和外部 API 管线做对照。
2. **像素风专用生成工具缺失**：PixelLab、Retro Diffusion 一类工具是独立游戏 2D 的常见选择，目前 0 次提及。WP8 认为像素风对单人程序可能友好，正需要这类对照。
3. **“程序手段补差距”的核心工具没有展开**：Blender 无头脚本（`bpy`）是减面、UV、LOD、批量导出的主要程序手段，目前 0 次提及（blender-mcp 出现 5 次）。“零人工修补、只用程序手段”这条基准，在 3D 上几乎完全依赖它。
4. **视频与图像的若干主流服务未覆盖**：Kling、Seedance / Seedream 等。按“商业和开源都要覆盖”的要求，应补核后决定纳入或说明不纳入的理由。
5. **动态事实没有复核机制**：模型、价格、许可每月都在变，目前散落在正文里。需要一张统一的“动态事实表”（事实、来源、核实日期、下次复核日期）。
6. **可读性**：每个资产页和模块页开头加“30 秒结论”：一张决策表，写明什么条件下选什么。正文段落拆短，中英文之间加空格，限定语按锚点压到每节一句。
