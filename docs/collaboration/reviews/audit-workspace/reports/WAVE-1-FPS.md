## 2. 总体判断与成熟度

**结论：FPS-Like 已超出单纯射击原型，具备可复现模拟、机器人对局、单点爆破规则、六回合换边训练赛和可恢复的浏览器客户端；但仍是开发中的战术 FPS 原型，尚未达到 brief 定义的完整核心交战与产品品质。**

| 维度 | 判断 |

| 枪械与移动手感 | 未达标／未验证：缺同输入 CS2 对照、硬件帧表现和非作者实玩判断 |

## 4. 关键发现

### F1 — Three.js / WebGL2 真实画面验收仍是最大品质缺口
brief 将 Three.js 作为主渲染路径，Canvas2D 只是 CPU 回退。client 文档记录当前云端浏览器使用 canvas2d-cpu，WebGL2 不可用；quality 文档记录材质与 ground 组合的六回合补验也运行于 CPU 回退。该证据证明流程，不证明 AI 材质、阴影、灯光、角色轮廓或材质层次正确。硬件 WebGL2 固定机位图、同状态对照和非作者盲评仍缺。
**影响：** 不能判断是否达到 Valorant 风格化清晰度目标，也不能据此把候选升级为默认品质结论。

### F2 — 枪械循环和移动手感有工程测量，缺 CS2 同输入对照
feel 文档记录 ground-v1 Game 级滑停约 350 ms、反向首次非正速度约 116.67 ms；接地修复将明显水平位移损失记录由 13 次降为 0。接地路径成本在 10 个移动 actor 的样本中，Game.step 单步中位数约由 0.333 ms 增至 0.678 ms（约两倍），仅是特定 CPU 样本。文档也明确缺 CS2 当前版本同输入录像、屏幕输入到反馈、144 Hz 表现和非作者手感判断。默认训练赛、ground-v1 与历史 movement-v2 不同，不能混用其数据。
**影响：** 可测量性和回归有所改善，但不能回答是否更像 CS2、更跟手或更好玩。

### F3 — 音频事件系统存在，战术听觉反馈未验收
client 文档记录 WebAudio 合成事件、距离衰减和左右声像；同时明确缺完整声学遮挡、武器动作制作、受击方向及击杀专属反馈。a1dbv TASKS 仍要求试听原混音／受伤声，检查命中与受伤区分、是否遮蔽敌方枪声及久听疲劳。本轮未试听，不能评价音质或空间定位。

### F4 — 六回合训练赛可玩，不等于完整战术 5v5
README 与 quality 文档记录 1 名玩家＋9 名机器人、单爆破点、六回合、三回合换边、整场结算与重开。2026-11-03 浏览器记录通过正常 UI 操作完成六回合，但后端为 Canvas2D CPU 回退。brief 明确该训练赛只是阶段 B 单点子轮，不代表双点、经济、投掷物、技能或联网完成。simulation 文档记录机器人观察接口限制墙后信息，失去视线后搜索而非开火，这是应保留的公平性基础。历史 1v1 批测进攻方胜率 63.5%／61%，高于 brief 40%–60% 目标；该数据较早，不代表当前训练赛平衡。
**影响：** 对局框架成立，但十个会开枪的实体不等于成熟战术团队行为。

### F5 — 最新提交改善资产生产可靠性，不是玩家品质提升
最新提交把 GLB／可选 Blend／manifest 先写入暂存区，成功后整体发布；失败保留旧资产族，rename 失败尝试恢复，回滚／清理失败保留恢复证据。真实 Blender 4.3.2 故障注入和三件 GLB 基线不变有记录。这是值得保留的制作链改进，但没有运行时资产或游戏源码变化，也没有新画面、GPU 或 gameplay 证据。

## 6. 与 CS2 核心体验的差距

| 维度 | 当前状态 | 主要差距 |
|---|---|---|
| 移动／停步／急停 | Game 级测量、ground 候选 | 缺 CS2 同输入录像、屏幕呈现和非作者对照 |
| 瞄准／后坐／弹道 | 有命令、视角记录、后坐与散布逻辑 | 缺逐发画面、连续压枪、停火恢复和实际命中反馈对照 |
| 命中／受击／击倒 | 有模拟事件与基础 HUD | 受击方向、击杀专属反馈及音画同步缺证 |
| 换弹／切枪 | 有模拟时序和弹药状态 | 分段手部动画、动作打断和音画接触点缺少验收 |
| 地图／掩体／视线 | 单点地图、三条路线、导航与遮挡判定 | 交战节奏、双点空间、可读性与多种子平衡证据不足 |
| 机器人 | 有感知约束、搜索和训练赛职责 | 缺复杂协同、经济选择、技能反制和战术质量评估 |
| 视觉／声音 | 有渲染与合成音频管线 | 缺 WebGL2 真实图、盲评、实际试听与声学遮挡 |
| 性能／兼容 | CPU 回归、构建、Canvas 回退 | 缺 WebGL2 硬件帧时间、输入延迟和设备覆盖 |
