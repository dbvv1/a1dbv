## F1 · 高优先级：通用复制命令覆盖已有指令与权限

**位置**：基线 [templates/README.md](https://github.com/dbvv1/a1dbv/blob/331e093db029627406eb030f5e5e876f1b03e11f/templates/README.md) 的“使用步骤”。该段没有空目录前提，直接 `cp -r templates/generic/{AGENTS.md,CLAUDE.md,REVIEW.md,.claude} <你的项目>/`。

**复现** **[经验：本轮确定性运行]**：临时项目预置 `AGENTS.md` 和含 `Bash(*)` deny 的 `.claude/settings.json`，执行该段原命令（仅替换目标占位符）；返回码 0，两份旧文件均未保留，settings 与仓库模板逐字相同。所有输入为合成内容，未操作真实用户配置。

复现程序（在基线检出目录执行；只写临时目录）：

```python
from pathlib import Path
import re, shlex, subprocess, tempfile

root = Path.cwd()
source = subprocess.check_output(
    ["git", "show", "331e093:templates/README.md"], text=True)
recipe = re.search(r"## 使用步骤\s*```bash\n(.*?)```", source, re.S).group(1)
with tempfile.TemporaryDirectory() as directory:
    target = Path(directory) / "existing-project"
    (target / ".claude").mkdir(parents=True)
    existing = {
        "AGENTS.md": "# Existing project rules\nKeep my project instructions.\n",
        ".claude/settings.json": '{"permissions":{"deny":["Bash(*)"]}}\n',
    }
    for name, body in existing.items():
        (target / name).write_text(body)
    result = subprocess.run(
        ["bash", "-c", recipe.replace("<你的项目>", shlex.quote(str(target)))],
        cwd=root, capture_output=True, text=True)
    print("exit_code", result.returncode)
    for name, body in existing.items():
        print(name, "preserved", (target / name).read_text() == body)
    print("settings_matches_template",
          (target / ".claude/settings.json").read_bytes() ==
          (root / "templates/generic/.claude/settings.json").read_bytes())
```

观察输出：`exit_code 0`；两个 `preserved False`；`settings_matches_template True`。本复现证明文件覆盖，不证明实际客户端如何解析合并权限。

**修订**：移除无条件整包复制，入口改为检查既有配置、先合并项目指令、按具体问题选组件。现有 Unity/Unreal 空项目安装规则有独立拒绝覆盖回归，不把本发现泛化为所有模板安装都坏。未另造安装器。

复用现有四条长期任务，不另建框架。当前优先级是 **[研究：本仓库判断，允许 dot 独立修订]**：
