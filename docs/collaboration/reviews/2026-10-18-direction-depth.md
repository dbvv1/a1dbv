# 核心方向与各工作线的内容深度复盘

核实：2026-10-18（UTC+8）。固定内容基线：37609f8c2877e72d7322fd0320b59a51ceaa2807。以下为 **[研究：仓内内容审阅与编辑判断]**，不是新外源研究、效果实验或新方向体系。依据AGENTS锚点、运行手册、BACKLOG、游戏细则与下列专题；主干、游戏分别独立只读审阅，主审核M6、核心结构和交付建议。

## 总判断

**方向成立，深度分布和内容组织需要调整。** 四条主线连接软件价值、能力补充、连续修改与交付；M1–M6／GA–GF组织维护，专题向读者提供选择。既有范围容纳通用AI coding、Codex／Claude、开放探索、游戏全链路与客户端深度，没有依据压成几个固定问题或改写锚点。

当前最强的是机制、契约、反证和失效条件。相对薄弱的是发现值得做的需求、在多个正确实现中追求更高质量、持续修改的结构取舍、下一位维护者的实际接管，以及探索成果进入生成任务后的结果。部分页面沿容易取得的历史修复链追加细节，具体任务的首选与竞争路线反而难找。这不等于全仓都浅，也不等于没有近期官方与社区材料。

普通软件工程知识、历史作品和游戏机制可以直接服务AI开发，不要求每项先证明AI净收益。应分别判断：它是否改变重要实现或质量选择；额外Agent能力是否带来增量；内容是否位于读者会寻找的入口。历史人工修复能支持第一项，不能自动回答第二项；缺模型对照也不妨碍有边界的工程判断。

有来源、L3、反证未丢和离线通过各有价值，都不能单独证明内容最值得采用。前沿性需要在重要选择上对照当前可行替代路线；优秀基础机制可以长期有效，新版本也可能不改变选择。本轮没有全网替代方案普查，不认证“全球最先进”。

- **18 §7“评审与协作规范”（基线106行起）**：原生包、实例身份、归档权限、旧对象与双向同步均可能决定交付，不能整批删掉。正文先让接收者选择当前任务和失败层，再取相关依据；具体维护过程留研究。继续补跨人理解与续改，避免用相似恢复案例替代整个接管方向。

### GA：资源类型不能合并成“AI美术是否可用”

依据03及现有资源分册。各类都有可用结论，下表写的是继续深入的差异，不声称这些内容从未涉及。

| 资源类型 | 已有内容的强处 | 下一步应回答的选择 |
|---|---|---|
| 2D／UI／图标／地块 | 原生UI、母版、像素换装、3D转精灵、图集、透明与地块边界 | 目标显示尺寸、方向数、动画和换装要求下，哪种路线能持续补齐同一套语义资产？像素风不天然省工，静态统一不证明动画统一 |
| 3D | 刚体／场景／变形、低模、UV、LOD、碰撞、模块化与可动部件 | 完整资产包、程序化配方、生成单件各能覆盖多少真实玩法要求？新增结构的代价是否推翻初次选型，而不只是换纹理是否成功 |
| 动画 | Motion Matching、Blend Tree、IK、距离／步幅扭曲、程序步态、重定向 | 所需动作覆盖、控制响应和动作承诺如何与制作／改稿负担共同决定路线？高级功能不是默认最佳方案 |
| 材质／VFX | PBR、投影、重复、卡片层次、序列帧、六向光照与运行预算 | 同一场景的风格、战斗可读性和设备预算怎样取舍？共享源修改能否传递到整套资源，不能以存在mask证明可编辑性 |
| 音效 | 语义、并发、密度、变体、空间位置与节奏；Rainboids有生产修改证据 | 同一需求的现成／合成／生成路线在整段体验和制作负担上如何比较？局部成功不外推到整套音频 |
| 音乐 | 乐句、状态、同步层、FTL／Factorio及DSP／Quartz运行机制 | 如何获得并持续修改兼容的音乐内容？运行时调度证据强于供给证据，拍点对齐不等于主题、情绪和发展连贯 |
| 语音 | 文本／非语言／完整配音、连续表演、字幕、供给与权利 | 哪类叙事收益值得承担持续重录与版本维护？TTS能力不等于表演质量，也不能把所有语音一律降为装饰 |
| 视频 | 引擎内／静帧／预渲染／生成、局部修改、音画拆分和跳过恢复 | 叙事目的、分支和节奏改稿是否值得视频生产成本？成片与价格不证明无人工修补的制作链 |

跨资源风格研究已存在于03§1.7及WP8，不应重新发明一份风格清单。应把共享身份、风格、结构的区别用于资源组合决策：某风格单张直出漂亮，却可能要求难以持续供应的动作或灯光，这是会改变玩法与制作路线的限制。反过来，成熟现成资源能提高质量上限时，应正面推荐，不因“不是生成”而降低价值。
