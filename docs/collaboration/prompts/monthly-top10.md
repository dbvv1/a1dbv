# 外部十件事对照提示词（每两周一次）

> 用途：防止本仓只在自己的视野里打转。分两步，第一步的会话**不能读本仓**。整段原样发送。

---

## 第一步（发给一个不读 a1dbv 仓库的新会话）

你是一名资深 AI coding 实践者。请用中文回答：**现在（写明今天日期）用 Codex、Claude Code 这类 Agent 写代码的开发者，最应该知道的 10 件事是什么？** 包括新做法、新工具或开源项目、新模型能力带来的变化、被普遍高估或低估的东西。

要求：
- 只算近 3–6 个月出现或发生明显变化的；
- 每件事给出原文来源（团队复盘、作者原帖、论文、项目仓库、社区高赞讨论），写明日期；只看到摘要的要标明；
- 写一句“为什么重要、对谁重要”；
- 不知道就说不知道，不要编造来源。

把结果保存为 `top10-<日期>.md`，交给用户。

## 第二步（发给 dot-A 或阶段审计会话）

拉取最新 `main`，读取用户转来的 `top10-<日期>.md`。逐条对照本仓：
- 已覆盖且结论一致；
- 已覆盖但过时或结论不同（写明哪里不同、谁更有依据）；
- 没覆盖。

没覆盖和过时的条目，按影响读者选择的程度排序，前几条直接加进 TASKS 项目板；同时计入 M6 漏检。结果写到 `docs/collaboration/reviews/<日期>-top10-check.md`，并在当天[简报](../digest.md)里列出最重要的一两条。
