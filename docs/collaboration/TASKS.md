- **dot-B（游戏）**：完整核心模块与高质量作品并行；Star-Rush为现有载体，后续类型案例按知识价值与交付能力扩展。验收受限只停对应环节，先交可运行／可接入产物；Game-Core-Knowledge按原分工。见[手册§9](LONG-TERM-PLAN.md#9-长期方向与当前承接)。
- **已有审计**：[方向指导](reviews/2026-10-23-direction-guidance.md)／[校准基线](reviews/2026-10-23-quality-followup.md)，不重复。

- **整体纠偏（10-25）**：推进完整能力与成品；[既有审计](reviews/2026-10-24-direction-delta-audit.md)保历史。A真实模型采用与比较，B研究／制作并行，沿手册与两份长期提示词执行，不新增流程。

- **自主续题**：按[手册](LONG-TERM-PLAN.md)逐次选题，交付／受阻即续；[A](prompts/2026-10-24-dot-a-continuation.md)／[B](prompts/2026-10-24-dot-b-continuation.md)。
