| [reviews/](reviews/) | 阶段审计和抽审记录，绑定精确提交；意见可以被反证推翻 |
| [prompts/](prompts/) | 当前长期提示词为 [dot-a.md](prompts/dot-a.md)、[dot-b.md](prompts/dot-b.md)（固定文件名，就地更新）；其余为历史存档 |
| [archive/](archive/README.md) | TASKS 已完成条目的归档 |
