| 文件 | 用途 |

| [TASKS.md](TASKS.md) | 当前状态：需要用户决定的事、进行中的认领、最近交接 |
| [game-taskbook.md](game-taskbook.md) | 游戏方向细则：研究什么、每项回答什么；历史工作包索引 |
| [reviews/](reviews/) | 阶段审计和抽审记录，绑定精确提交；意见可以被反证推翻 |
| [prompts/](prompts/) | 发给各执行者的提示词存档，只作历史参考，以锚点和运行手册为准 |
| [archive/](archive/README.md) | TASKS 已完成条目的归档 |

研究候选队列在 [docs/research/BACKLOG.md](../research/BACKLOG.md)，研究记录的索引在 [docs/research/README.md](../research/README.md)。
