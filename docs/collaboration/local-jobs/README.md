# 本地模型任务入口

A／B 在本目录一任务一 Markdown，按[细则§2.2](../operations.md#22-本地模型协作)下发；本页是任务字段、接收与恢复合同。分支名只用于发现，不替代 owner、用户授权和内容检查；任务不能扩大账号、材料、费用或破坏性操作权限。

## 任务卡

必填 `id`、`owner`（dot-A／dot-B）、`status`、`target_repo`、`base_ref`、`result_branch`；可选 `accept`、`kind`（见下节）、`page`（`<本仓路径>[@<分支或提交>]`，缺省 main，全文附给模型）。

正文写目标、Skill／规格、写入范围、验收标准；未结束卡不超 80 行。“当前结果”只留产物、欠项和下一步，由接收端每单元整体改写；返工要求另写“修改要求”，过程进提交说明。逐项清单写清顺序。

## 发现与执行

接收端每次 fetch main、`dot-a/*`／`dot-b/*`。只导入新增 ready 或基于当前 main 的 revision_requested 任务文件，不合整条分支；旧版本反馈由负责人在最新 main 重写。先将 running 快进推到 main，再调用模型；只续接本人认领的 running，其他执行者的不碰，空队列只 fetch。单写者遵循[细则§2](../operations.md#2-分支与交付)。

每任务使用目标仓库独立 worktree，Claude Code＋DeepSeek v4.1 flash 按 `kind` 跑原生 Workflow：

| kind | 固定流程 |
|---|---|
| `build`（默认） | 实施后三名审查者并行看读者可用、事实与链接、实际运行，修到全过，最多三轮 |
| `reader-test` | 真实任务仓，读者只照 page 全文做，在结果分支记卡点、不改页面；非读者按任务验收核对，区分页面卡点与执行能力 |
| `explore` | 三路收集候选、核实链接，整理再审 |

逐项清单每单元约 60–90 分钟；同时最多 4 个任务。普通单元超 2 小时、探索超 4 小时或连续两次失败标 blocked，写恢复条件，按原合同保全与续接。模型只改文件；脚本做提交、公开扫描、适用检查及结果推送。不设人为调用／token 预算，遵守实际限流，停止无新信息重复，不开新收费服务；Windows 原生跑 check_repo＋check_public，完整离线门禁只要求 POSIX。开机登录、扫描周期和超时未领取通知按[细则§3](../operations.md#3-dot-运行保障)。

## 恢复与防重放

同一 id 不重复执行。重启先核原调用；调用、工具或登记进程未确认结束时保留本地隔离，改 ready 不能绕过，由维护者核清再续。确认结束的探索重试，在同单元、同正文及流程版本下复用原生记录已完成的收集；已完成追踪只并回候选，本轮分组继续追踪并重核链接。

输入变化由负责人写差异并改 revision_requested，沿原分支续；cancelled 请求在安全边界停止并保结果，状态本身不证明退出。原因、恢复条件留原卡“当前结果”；未知重试与外部副作用对账按[细则§1](../operations.md#1-发布与恢复)。

## 接收

**自动接收（`accept: auto`）**只用于 a1dbv 内、负责人已定规格的常规 build（正文改写、已定提纲模块整合、检查脚本修复）。非作者审查与[手册§7](../LONG-TERM-PLAN.md#7-交付流程)检查全过后，脚本按细则§1 每单元合入 main；全部完成才标 accepted 并写合入提交，负责人事后抽查，有错直接修 main。新方向、删除、案例默认分支、未定规格及 reader-test 不用自动接收。

其余产物推目标仓库的 `relay/*` 结果分支（卡片 result_branch），回写 review_ready；本队列不授权合入产品默认分支或部署。负责人每次开工／续题在可写分支接收或给具体返工要求，无需用户转发；重叠实现先对照，选采用、保留候选或拒绝，放弃写一句理由。接收端将明确决定的原文及来源带回 main，不代判 accepted。

accepted 写清具体范围、版本和剩余项；工程可收而听感等独立项待验时部分接收，继续独立工作，最终品质仍待判。遗漏、页面卡点或目标未成保留未通过，不自动再盲读；返工用 revision_requested，不冒充新读者首次实测；阻塞用 blocked。

公开卡与产物只含可公开材料，不含本机路径、私人会话 id、凭据或敏感原始日志；检查实际新增产物并按细则§1 公开扫描。真实验收按任务要求，不以模型自报替代。Git 文件本身不唤醒任务。
