## 要解决的完整问题

现有 2D 页覆盖工具分档、风格、像素动作、瓦片、图集、压缩和透明边，但读者还需要一条从美术规格到整套制作、运行接入和持续修改的主流程。将已有分散研究整合为完整生产模块：没有专职美术的程序员如何组合现成资源、AI 与可编辑源，做出同一作品的角色、场景与 UI，而不是逐张生成后再补救。

以原创俯视角小型探索／动作游戏为贯穿例：一个角色的必要动作、一族相互连接的地形／装饰、少量功能图标及原生 UI。不是新增完整游戏项目，也不是要求实际调用生图服务。明确目标显示尺寸、轮廓与色彩、动作节奏、镜头／缩放、画布与 pivot、遮挡和地形邻接如何共同约束资产。第二改为“新增一种地形并保持旧地图，再给角色换一件装备且保动作可读性”；需要新动作源或遮挡规则时正面说明如何生产，而不是只写撤回。
