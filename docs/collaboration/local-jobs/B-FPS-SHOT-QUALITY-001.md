## 正常输入观察

1. 从正常菜单进入，保持实际 renderer／设置，记录浏览器版本、GPU 或软件 renderer、视口与缩放、时间及输入工具。需真实 Three.js／WebGL2；CPU 回退另列，不代替三维结论。
2. 用真实鼠标键盘完成掩体窥角→松方向键制动→首发→短连射→退回掩体装填→再次出枪；另做反向键制动，与松键路径区别记录。鼠标锁定、WASD、左键、R 按 README 操作，允许通过正常重开重试。
3. 看动态准星在移动、停步、连射和恢复时是否帮助读懂射击；分别记录首发、连续射击、命中／落空、后坐恢复、装填重新就绪与开火／命中音。未打中就如实记未打中，不造“命中成功”。
4. 只从正常输入控制对局，不注入位置、血量、命中、胜负或调用隐藏 state 控制；只读诊断可记录实际事件，不改变游戏。不跑 smoke、自动 bot 或固定输入回放代替自然操作；回放最多是功能证据。
5. 保留一段覆盖完整循环的连续短录像和同一 viewport 的本作截图，标注同一版、实际输入、阶段与结果。不得把出手帧写成命中帧，也不把分属两次会话的画面当连续过程。
