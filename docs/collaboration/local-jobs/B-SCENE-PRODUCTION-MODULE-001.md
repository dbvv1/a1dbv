## 要解决的完整问题

让没有专职美术的程序员真正知道怎样做出一个有主次、能移动观看、能继续改的 3D 场景，而不是读完路线表仍不会开始。现有 3D 页已经有完整片段流程和不少强参照；本项复用它们，把分散的模块建筑、植被、材质、局部编辑、优化消费者和二改经验连接成可照做的生产模块，不重新收集工具名单，不做纯风格压缩。

以一个原创小型探索场景为贯穿例：入口引导到主要地标，中间有一个可交互物件与一处视线转折。无需新仓库或完整新游戏，也不限定赛车。交代相机与可玩尺度、主辅形体、近中远层、材质族与灯光、地形／建筑／植被供给、运行接入、第二次需求修改之间的因果关系。第二改为“改成傍晚，打开入口到地标的视线，并保留可交互物件的使用空间”；不是单独取消／恢复边界小题。
