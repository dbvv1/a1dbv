## 实际验证与结果

提供可复现的`npm ci`、`npm test`、`npm run sim -- --games <N> --seed <S>`。单测覆盖正常链、无效命令／目标、死亡／终局、控制与技能时间、同种子同命令重放哈希；实际Node批量对局输出异常、卡死、时长、阵营胜负及每技能施放／命中／伤害统计。先核最小一局再跑brief的200局；镜像对称置信区间另用至少500局与多个种子，不把200局冒充已满足500局要求。说明统计口径、失败样例及可重放输入；超时／未终局不悄悄排除。brief的80%难度胜率、8–12分钟和对称区间是目标，报告实得与偏差，不能改标签掩盖失败或凭源码声称收益。

当前任务不做渲染／交互，因此浏览器smoke、WebGL、视觉听感和玩家手感未验证；无画面自测通过不等于可玩。实际源码阅读、Node测试／批量运行、独立审查和未验证项分别报告。实施后由宿主另取非作者、与实施上下文分离的一次有效独审，核原需求、代码与真实测试；实施者不得自写宿主审查回执。保留原失败及差量修复，不用再造全文审查替代修实质问题。
