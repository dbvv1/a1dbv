# 实用工具：先解决日常问题，再决定装什么

> 核实时间：2026-10-12。来源与采用边界已做限定文档审阅；不代表运行验证。
> 面向 Codex、Claude Code 等 AI coding 工具的使用场景，考察社区开源项目与官方工具，不按 star 排名。
> 本轮只读文档、release、部分源码与用户原帖；没有安装运行这些工具、访问个人日志、验证 Windows 实机或测得生产力提升。

## 按问题进入

| 问题 | 原生基线 | 增量候选 | 判断 |
|---|---|---|---|
| 哪天、哪个会话消耗异常 | Codex `/status`、`/statusline`、服务商账单 | [ccusage](usage-and-sessions.md) | 🧪 历史诊断；估算不是账单或剩余额度 |
| 多终端、多 Agent 工作树难找难清理 | Codex worktree/Handoff、Git worktree | [Worktrunk](worktrees.md) | 🧪 有跨终端痛点才试，优先验清理安全 |
| 大仓库找引用慢、库 API 总用错 | 文本搜索、IDE、锁定版本官方文档 | [Serena / Context7](code-and-docs.md) | 🧪 分开试；语义代码检索与文档检索不是同一能力 |
| Agent 看不到页面真实错误 | 项目 Playwright、人工 DevTools | [Chrome DevTools MCP](browser-feedback.md) | 🧪 补网络/控制台/性能诊断，已有工具够用就不叠加 |
| 相同窄评审要在每个 PR 重复做 | 手动 Codex 评审、确定性 CI | [Codex Action](review-automation.md) | 👀 先确认隔离 runner、权限和预算，再试用 |
| 多账号与网关配置混乱 | 官方登录、明确账号和项目边界 | [账号与网关](accounts-and-gateways.md) | 按显式切换或请求调度分开选；按案例条件评估 |

表中是 **[经验：采用判断]**，不是用户已安装清单。✅ 采用 / 🧪 试用 / 👀 评估 / ⛔ 暂缓沿用 [证据约定](../README.md)；“不需要”表示没有增量价值，不是质量差。

## 这个独立模块负责什么

读完应能判断：原生为什么不够、工具补哪项能力、接触哪些数据与权限、在哪个版本环境值得试、什么结果支持保留或撤回。

[04 MCP](../04-mcp.md) 继续解释连接机制，[05 Skills](../05-skills-and-plugins.md) 解释能力封装，[09](../09-review-and-quality.md) 保留评审策略，[23](../23-browser-verification.md) 保留产品验收方法，[24](../24-community-workflows.md) 保留社区方法论。这里专门处理**选型、接入边界、运维与退出**，不再复制一套完整流程。

## 最小采用路线

以下为 **[经验：设计，未执行]**：

- **✅ 采用原生基线与证据记录**：显示当前模型、权限、目录；并行代码隔离工作树；验收保留可检查产物。
- **🧪 一次补一个明确缺口**：从本周真实问题出发，不因本文出现六类就全部安装。
- **👀 有发布但缺本机证据仍是评估**：Windows、WSL、PowerShell、Git Bash 分开记录，“有 Windows 包”不等于组合都通过。
- **⛔ 暂缓越权或不可恢复方案**：关闭安全防护、未经授权上传日志或导出/传输登录包、无法回滚。明确授权的本地凭据存储/迁移单独审查数据流、访问权限和恢复机制，不一概排除。
- **不需要也应明确记录**：一两棵工作树未必需要管理器；官方文档检索已稳定未必需要 Context7；已有浏览器工具能给同样证据未必再加控制入口。

## 一张试用记录卡即可

问题 / 原生对照 / 固定工具版本 / OS 与 shell / 数据流向 / 权限 / 同任务产物 / 人工与维护耗时 / 失败与回退 / 最终决定。复用 [22 评估](../22-agent-evaluation.md)，不新增“装完即通过”的表演性检查。

保留条件：获得原生路径没有的有效结果，或减少可解释的人工工作，且风险可接受。少几个调用、模型自称高效、一个漂亮截图都不够。升级改变配置、日志格式或权限后重测；旧成功不能自动沿用。以上为 **[经验：设计]**。

## 前沿变化只在影响选择时追踪

ccusage 的统一报告仍受 Codex 日志格式影响；Context7 既有 MCP 又有 CLI + Skills；Serena 稳定版与 main 功能、许可存在差异；官方 Codex Action 也要固定运行依赖。这些事实及来源见各分节。新闻放 [13](../13-frontier-radar.md)，不复制 release 清单，不将作者推广或单个 issue 写成社区共识。
