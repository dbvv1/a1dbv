## 5. E2：子 Agent 的成本

**单文件的小定位先用单 Agent。** 两组各三次都找全 29 处；单 Agent vs 两子 Agent 的平均墙钟 17.6／47.1 秒，API 等价估算 $0.0055／$0.0109。是同任务重复，不是 29 个任务，未测独立视角和大上下文效益。[提示、分组与明细](research/2026-10-12-experiment-records.md#5-e2子-agent-的成本)

## 6. 如何在自己的仓库复现

固定好／坏基线，保证一次只改所测因素；先证明新增用例能在已知坏版本失败，再比较受检补丁、实际输出、时间与成本。保存失败和所有尝试，三次先导不报稳定倍数。用[当前评估做法](22-agent-evaluation.md)或查[历史命令](research/2026-10-12-experiment-records.md#6-如何在自己的仓库复现)。

## 10. E6：路径 Hook 的确定性回归

**修改路径 Hook 同时检验别名、解析失败和输出 JSON。** 原基线暴露三类问题：

- `./`/`..` 漏匹配；
- 解析错误被返回 0 掩盖；
- 控制字符破坏 JSON。

修正后 python3 与 jq 后端各跑同一组 **26 个测试方法**通过，通用/Unity/Unreal 三份脚本保持一致。具体基线、命令和路径反例详见本节依据。

**局限**：状态 1 不等于运行时 deny，词法归一也不解析符号链接，辅助 Hook 不能当作文件系统安全边界。
