# Unity 项目受保护路径规则（由 hooks/protect-paths.sh 读取）
# 格式：<deny|ask> <glob> [原因]；glob 相对项目根目录，* 可跨目录；第一条命中的规则生效

deny  Library/*        Unity 生成目录，禁止编辑
deny  Temp/*           Unity 生成目录，禁止编辑
deny  obj/*            构建中间产物，禁止编辑
deny  Logs/*           日志目录，禁止编辑
deny  UserSettings/*   个人编辑器设置，禁止编辑
deny  Build/*          构建产物，禁止编辑
deny  Builds/*         构建产物，禁止编辑
deny  *.meta           禁止直接编辑 .meta（GUID 损坏会导致引用丢失）。新文件让 Unity 生成 meta；移动文件请用 git mv 连同 .meta 一起移动
ask   *.unity          场景是 YAML 序列化资源（含 fileID/GUID 引用），手改风险高，建议用 unity command eval / Unity MCP。确认直接编辑吗？
ask   *.prefab         Prefab 是 YAML 序列化资源，手改风险高，建议用编辑器 API。确认直接编辑吗？
ask   *.asset          序列化资源，手改风险高，建议用编辑器 API。确认直接编辑吗？
ask   *.mat            材质是序列化资源，建议用编辑器 API。确认直接编辑吗？
ask   *.controller     动画控制器是序列化资源，建议用编辑器 API。确认直接编辑吗？
ask   *.anim           动画是序列化资源，建议用编辑器 API。确认直接编辑吗？
ask   ProjectSettings/*      项目设置影响全项目和所有平台，确认修改吗？
ask   Packages/manifest.json 包依赖影响全项目，确认修改吗？
ask   Assets/Plugins/*       第三方插件目录，建议加包装层而不是直接修改。确认修改吗？
