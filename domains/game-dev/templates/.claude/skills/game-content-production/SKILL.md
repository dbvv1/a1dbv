# 成套内容制作

范围：$ARGUMENTS

角色、场景、材质、动作、特效、声音成套制作，与玩法、手感并行。

## 1. 从标杆列内容清单

- 看标杆的完整一局（一场对局、一个回合、一场比赛），列出玩家看到和听到的全部内容：角色（含各自的动作表）、敌人与中立单位、场景（地表、围合、建筑、地标、植被、天空）、道具与武器、技能与命中特效、音效、音乐、语音或提示音、界面（HUD、商店或装备、结算）。纵切片是完整一局的缩小版：类别齐全，数量按切片缩放。
- 每项写规格：在游戏机位下的屏幕大小、面数与贴图预算、动作清单（如待机、移动、攻击两段、施法、受击、死亡）、需要的变体。规格从玩法和目标设备推出。
- 玩法和数值借什么，按所在项目的规则（a1dbv 见游戏方向细则§6“只借玩法”）。

## 2. 先定风格，再做量

- 用 [game-quality-pass](../game-quality-pass/SKILL.md) 的目标效果图写一页风格说明：形状语言、头身比、调色板、材质族、纹素密度、着色方式（如卡通渐变或 PBR）、描边与光照设定。
- **风格受可得的成套资源约束**：免费成套资源多为低模风格化；对标写实作品（如 CS2、地平线）时，要么用风格化重新诠释标杆的结构、光照和材料层次，要么在用户同意付费时用写实成套包。选定后把离标杆的这部分差距写明。
- 先做 3–5 件“标准件”（一个主角、一个敌人、一段墙、一件道具、一个技能特效），放进游戏机位和光照下定稿；之后每件新内容都和标准件同框比较，不合格不进游戏。
- **统一风格靠统一处理，不靠单件精修**：全部模型用同一套材质或共享调色板图集、同一光照、同一后处理；尺寸、轴心和朝向按规范归一。来源不同的资源经过同一套处理，才能放在一起。

## 3. 按顺序取得

具体工具、参数和许可核对按制作链页选：a1dbv 见 `domains/game-dev/assets/` 的 [3D](../../../../assets/3d.md)、[动画](../../../../assets/animation.md)、[材质与特效](../../../../assets/materials.md)、[音频](../../../../assets/audio.md)。取舍顺序：

1. **成套的现成资源**：同一作者成套出的、与风格说明一致的套件优先，同一套里取得越多越统一（免费的如 KayKit、Quaternius、Kenney，材质与天空用 ambientCG、Poly Haven；付费成套包和 Fab、Asset Store 由用户决定）。动作用成套动作库重定向。
2. **程序生成**：地形、道路、植被散布、建筑立面组合、粒子特效、界面图形；第一人称武器的后坐、摆动和换弹位移也常用弹簧驱动的程序动画加少量关键帧。
3. **AI 生成**：小样比较、写制作链知识、少量采用，有效才扩量。2D 用对话或 Codex 生图。规整硬表面件由 agent 写 Blender `bpy` 脚本（或 MCP 看视口），重跑改参数；有机件用图生 3D。Tripo P1／Hunyuan3D 的面数、PBR、减面与贴图选择见 [3D 同机位实测](../../../../assets/3d.md#实测三种来源同提示同机位2026-10-28)，保留 2026-10-28 比较条件。变形角色先用有拓扑骨架的成套角色，动作另验。
4. **音频**：先用 CC0 与免版税音效库（如 Freesound 的 CC0 条目、Sonniss 的 GDC 免版税包）；生成类先核权重和生成结果的许可（如 MusicGen 权重为 CC-BY-NC，不能商用）。
5. **许可是第一道门**：代码、模型权重和生成结果能否商用，取得前查清，写进素材目录的来源说明。不允许再分发原始文件的（如 Mixamo 的原始动作），只提交处理后并入作品的产物。

## 4. 用脚本接入

- 归一与导出写成可重跑的脚本（如 Blender 无界面 `bpy`：缩放、轴心、减面、材质替换、LOD、碰撞体；再用 glTF-Transform 做 meshopt 与 KTX2 压缩）。重跑一次就能把整批内容按新规范重新导出。
- 网页：Three.js 用 `GLTFLoader` 配 `MeshoptDecoder` 与 `KTX2Loader` 加载；按目标设备定首屏下载体积、三角面与 draw call 预算，在拍摄脚本里一并记录。Unity 用导入预设与 `AssetPostprocessor`，Unreal 用 Interchange 管线，Godot 用导入设置与导入脚本。
- 每批内容进游戏后拍阵容图：全部角色或同类道具在游戏光照和机位下并排，一眼看出谁不统一。

## 5. 在完整一局里验收，并做第二次修改

- 验收看完整一局：从开局到结算，按 [game-quality-pass](../game-quality-pass/SKILL.md) 的机位和非作者判定对照标杆，不看模型数、素材数或测试数。
- 第二次修改：改一条风格规则（如调色板或头身比）或加一个新角色，按原流程重做一批，记下要重做多少、多久、哪里断了。断的地方就是制作链要补的环节。
- 采用结果按 [game-quality-pass §5](../game-quality-pass/SKILL.md#5-写回知识) 回写制作链页。

**依据**：2026-10-28 Tripo P1 与 Hunyuan3D 3.1 Pro 四件同提示小样的同机位渲染；2026 年 AI 3D 生成工具对比（Meshy、Tripo 能力说明多为厂商来源，以实际产物为准）；a1dbv 制作链页的既有选择（3D、动画许可）；AudioCraft 的模型许可。核实 2026-10-27。
