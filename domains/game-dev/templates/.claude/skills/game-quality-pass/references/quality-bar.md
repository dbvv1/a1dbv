# 质量标准：什么算达到标杆

**达到标杆指玩家在同类机位、同类操作下，看到和摸到的质感与标杆同一档；内容原创。** 功能能跑、测试通过只是门槛。标准分画面、手感、内容三条线，每条都有达标线和测法。达标前的取舍规则由所在项目定（a1dbv 见游戏方向细则§6 第 3 条）。

## 1. 记分卡

每个案例的 `docs/quality.md` 开头放一张记分卡，每轮更新，其余内容放在它后面：

| 线 | 达标线 | 当前（分数或测量值） | 最大差距 | 下一单元 |
|---|---|---|---|---|
| 画面 | §2 | 每个命名机位的盲评分 | 一句话 | 改哪一层 |
| 手感 | §3 | 规格表逐项实测值 | 一句话 | 改哪一项 |
| 内容 | §4 | 完整一局清单的覆盖率 | 一句话 | 补哪一批 |

记分卡写现状和差距，不写免责说明。哪条线离达标最远，下一个单元就做哪条；线内从非作者审查者给出的第一处差距开始（SKILL §4）。

## 2. 画面达标线

1. **目标效果图**：每个命名机位一张，按 [SKILL §2](../SKILL.md#2-改之前先查别人怎么解决) 用图像编辑模型从当前截图重绘 2–3 张候选；按非作者评分选，候选同时进待人工验收供用户改选，不等用户。目标图先由非作者对照本地的标杆同机位参照按第 3 条打分，≥4 才能作为这个机位的达标线，选定后提交进作品 `docs/`；风格换代时重做。
2. **层清单齐全**：正常游玩机位里，[SKILL §3](../SKILL.md#3-改一整层让整个场景同时变) 的七层都已做过一轮，没有哪一层还是缺省状态（无环境光、无色调映射、平涂地表、素面大块、角色小到看不清轮廓、关键动作没有特效或声音、调试字样的界面）。
3. **盲评**：两个互不知情的非作者审查者各自只看 [当前截图 ｜ 目标图] 两张，答“像不像同一款游戏的同一品质档”，1–5 分：1 原型或灰盒，2 有统一风格但明显像素材拼装，3 像完成度不错的独立游戏，4 与目标图同档、只差细节，5 难分高下。另问“玩家第一眼最大的三处差距”。取两人中的较低分。作品 `docs/` 留存 1–5 各档的锚定样图，评分时一并给审查者。**每个命名机位 ≥4 分、三处差距里没有 SKILL §3 前三层的问题，才算画面达标。** 迭代和盲评用固定画质档的软件渲染截图即可（口径见 SKILL §1）。

## 3. 手感达标线

1. **规格表**：在作品 `docs/feel.md` 列出本品类的手感项（各品类的项和标杆数值见 [feel.md](feel.md)），每项写标杆值、来源、本作取值和取值理由。本作是原创作品，取值与标杆相差 ±20% 以内；超出的写明设计理由，并经非作者对照确认手感不更差。
2. **实测**：用 [feel.md §5](feel.md#5-测量与对照) 的输入回放和逐 tick 日志测出本作每一项的实际值，与规格表并排。只写“已实现”不算，测不出来的项先补测法。
3. **反馈同帧**：每个关键动作（移动起停、开火或施放、命中、击杀、碰撞）都有画面、声音、镜头三路反馈，按拍摄模式录像逐帧核对同帧到达。
4. **非作者对照**：同一段输入的本作录像与标杆录像（取自公开实机视频，只留本地）并排给审查者，问“哪一项最不像”，答案进记分卡的最大差距。
5. **人感**：用户在场试玩时请其按规格表各项打分；不在场时记为“实测达标、未经人感”，这一档即算手感达标，人感记入待人工验收，之后的打分推翻实测时回到未达标。

**规格表逐项实测落在取值范围内、反馈同帧、非作者对照找不出比“细节”更大的差距，才算手感达标。**

## 4. 内容达标线

1. **清单**：按 [game-content-production §1](../../game-content-production/SKILL.md#1-从标杆列内容清单) 列当前阶段完整一局所需的内容（角色及动作表、敌人和中立单位、场景各层、道具与武器、技能与命中特效、音效、音乐、界面），数量按 brief 的阶段范围定；由非作者核对类别是否齐全。
2. **每件过标准件**：非作者判定与该类标准件同框比较不掉档；正常游玩机位里没有占位体、调试材质和缺动作的角色。
3. **覆盖率**：清单中过了第 2 条的件数 ÷ 总件数，记进记分卡；**100% 才算内容达标。**

新阶段的新增内容一进作品就按同一标准验收。

**依据**：本 Skill 的分层与盲判方法；[feel.md](feel.md) 的手感依据；Riot [《Clarity in League》](https://www.leagueoflegends.com/en-gb/news/dev/clarity-in-league/)与《Updating Summoner's Rift》的可读性原则；2026-10-29 三个案例 main 的实际截图。核实 2026-10-29。
