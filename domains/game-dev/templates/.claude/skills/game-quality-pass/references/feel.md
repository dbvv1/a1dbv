# 手感：先修输入到画面的管线，再按标杆数值调

**手感差多半不是参数没调好，而是管线和运动模型不对：视角等逻辑帧、松键即停、开火用定时器、动作没有前摇后摇。** 先按 §1 修管线，再按品类换成标杆同类的运动模型（§2–4），最后用 §5 的回放和曲线对着标杆调数。

## 1. 管线（三品类通用）

- **固定步长模拟、渲染插值**：模拟按固定 tick 推进，渲染用上一 tick 与当前 tick 的状态按剩余时间比例插值，60 Hz、144 Hz 屏都平滑（Fiedler《Fix Your Timestep!》）。不要让渲染帧率决定模拟步长。
- **视角不等 tick**：第一人称和追尾相机的鼠标视角在每个渲染帧直接作用到相机，开火时把当帧视角随命令送进模拟；30 Hz 逻辑帧下等 tick 转视角会有约 33 毫秒的台阶感。
- **原始鼠标**：网页用 Pointer Lock，`requestPointerLock({ unadjustedMovement: true })` 关掉系统鼠标加速，不支持时回退普通锁定；灵敏度与标杆换算一致（同 cm/360°）。
- **输入不丢**：每帧开始采样一次，按下和松开都带 tick 进命令；同一 tick 内按下又松开也要生效一次。
- **量延迟**：拍摄模式回放输入，数从输入 tick 到第一处可见变化的渲染帧数。视角、移动起步、开火的第一处反馈应在下一个渲染帧。

## 2. FPS（对标 CS2／VALORANT）

- **移动用加速度与摩擦，不用匀速开关**：Source 引擎的做法是每 tick 先按摩擦减速（速度低于 `stopspeed` 时按 `stopspeed` 算摩擦量），再沿期望方向补速度，补量为 `accel × dt × wishspeed`，且不超过与期望速度的差（[Source SDK 2013 `gamemovement.cpp`](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/shared/gamemovement.cpp) 的 `Friction` 与 `Accelerate`）。这样“松键滑停”和“反向键急停”自然出现，急停快于滑停。
- **精度随速度**：移动不准度按当前速度÷武器最高速插值，低于阈值恢复精准，跳跃和落地单独加大；首发精准。
- **后坐**：固定弹道表（前几发上扬，之后左右摆）决定弹着点，另加视角上抬用弹簧回位；停火后后坐按时间恢复。射速用累加器按 tick 精确出膛，不用 `setInterval`。
- **第一人称动画**：待机呼吸、随速度的移动摆动、开火后坐、分段换弹（可被切枪打断）、切枪时间；用弹簧驱动的程序动画加少量关键帧。
- **命中反馈同帧**：枪口火光、弹孔贴花、命中音（爆头单独一档）、准星命中标记、受击者闪动、击杀提示。视场角与眼高见 [genre-targets.md](genre-targets.md)。

## 3. MOBA（对标英雄联盟）

- **右键移动**：按下当帧转向出发并显示点击标记；按住右键持续跟随光标；停止键立即停。
- **普攻分前摇与冷却**：攻击计时 = 1 ÷ 攻速，前摇占其中一个比例（按英雄定），前摇必须站定，被移动打断则计时清零；前摇结束出伤害，之后可以移动，这是走 A 的基础。前摇完成前 1 个 tick 内的新指令不再取消攻击，出手后再锁 1 个 tick 不接受输入。
- **指令缓冲**：前摇或施法中输入的下一条指令排队，结束当帧执行，不吞输入。
- **施法**：范围／方向指示器，快捷施法与按下松开施法两种；施法时间内能否移动按技能定义。
- **反馈**：技能命中特效＋音效＋受击闪白＋数值飘字；控制效果有明确图标与特效；补刀金币音。镜头可锁定或边缘滚动，一键回中。

## 4. 公路竞速（对标地平线，街机拟真）

- **轮胎**：侧偏角到侧向力用“线性段—峰值—下降”曲线（简化魔术公式），纵向滑移同理；加减速与转向时的前后左右载荷转移决定转向不足或过度。
- **转向**：转向速度和最大转角随车速降低；驾驶辅助（牵引力控制、稳定控制、ABS、反打辅助）做成可切换项，默认对新玩家开启。
- **漂移**：手刹或重心转移进入，油门与反打维持，出弯回正；漂移角和持续时间可测。
- **速度感**：视场角随速度、相机弹簧跟随与延迟、轻微抖动、路边件密度与运动拖影；引擎音按转速与负载混合多段采样，胎噪风噪随速度。

## 5. 测量与对照

- **本作**：拍摄模式回放固定输入脚本，每 tick 写日志（位置、速度、视角、散布、动作状态、事件），画曲线。脚本示例：全速前进 1 秒后松键／按反向键；急停后立即连射 10 发；点地移动 0.2 秒后点另一处；普攻中途移动；60 km/h 入 90° 弯。
- **标杆**：同一动作的标杆录像按已知帧率逐帧量（停步帧数、弹着点位移、点击到转向帧数、车速表读数），或用下表数值。录像只在本地使用。
- **对照**：曲线叠图加录像并排给非作者，问“哪一项最不像”。
