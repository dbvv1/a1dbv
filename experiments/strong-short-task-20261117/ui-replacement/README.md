## 方向会话预检合同

1. 为第一候选独立检出上表 SHA。只将相应 HTML 复制为目标检出根目录 `preflight.html`，同目录已有该版本 `Sortable.js`；不需要 npm 安装，不读取上游修复提交。第二候选如需检查，另建其固定 SHA 检出。
2. 在检出目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，本机真实浏览器打开 `http://127.0.0.1:8765/preflight.html`。如端口占用选空闲端口并记录；不外网暴露。记录 OS、浏览器、Node/Python、GPU/查看工具、实际命令、文件哈希。
3. 第一候选必须在拖动开始期间截图与读取 start 数组，并在释放后读 sort/end；重复三次。第二候选记录重建前正常跨列表拖动，再按按钮与拖动三轮，保存错误或无错误证据。不得通过编辑库、注入错误、猜时间条件来制造命中。
4. 出现与原报告一致的缺陷才标 reproduced；未出现为 not-reproduced；工具失败为 blocked。每项记录实际动作、屏幕与日志、预期/实际、耗时和环境成本。第一项未复现/阻塞才检查第二项；两项均未复现则返回缺口，不启动模型、不再自行换题。
5. 首个复现项返回候选名、完整 SHA、实际步骤、截图与事件日志、固定运行环境。dot-A 核收后将该项提升为成对 ready 卡；**本预检卡本身不授权启动任一模型臂**。准备好的两份输入无需方向会话重新设计提示。

## 已备好的成对输入与冻结接口

[原协议](../README.md)的模型、隔离、2 小时上限、质量优先、计时/费用/返工分账规则不变。替补 UI 题仍短任务先、现行后，Click 的安排不变。选定时冻结 `inputs/<候选>/short.txt`、`current.txt`、所选页面哈希和 `RUN-ENV.txt`；current 仅把[原推荐](../baseline-prompt.txt)槽位填入问题事实，不添加三审/拆卡。两臂允许同样的看图、长回合与工具权限。

调度者各自在两个独立目标检出中放同一 `preflight.html` 和 `RUN-ENV.txt`，只把对应提示全文交模型，不暴露方法名、另一份提示、a1dbv 或本协议。RUN-ENV 仅含上述版本/命令/工具、实际复现步骤与观察，不含解法、标签或评价；若预检步骤与现有提示不同，先同步改两份并核收冻结，不临场只改一臂。

质量矩阵在模型启动前冻结：fallback 核心为 start/sort/end 数组无克隆、三个原始 ID 各一次且顺序正确；兼容为正常排序、非 fallback、事件语义、取消拖动后列表不丢失。destroy-recreate 核心为同 group 重建三轮均能跨列表拖动、无未捕获异常；兼容为重建前行为、单次拖动事件不重复、项目现有销毁契约。两题都查新增回归测试、项目适用检查、控制台与代码维护质量，不要求不存在的类型/构建入口。首交标签隐藏盲评后才看方法与费用。

交回 `results/PREFLIGHT.md`（运行时创建）与必要脱敏证据；未入选候选不运行模型。卡片与准备工作不算答案页变化。
