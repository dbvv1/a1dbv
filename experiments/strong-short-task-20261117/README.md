# 强模型短任务与现行推荐：两题成对先导

**状态：已设计，未运行模型。** 11-17 用户指定最高优先候选：真实结果反馈、三段短任务、强模型长回合与较少流程约束。这里比较两套提示包，不把差异归因单一因素；两道窄 bug 题仅能发现问题，可能出现双方全通过的天花板，不能证明通用或游戏创作优劣。

## 启动合同（仅方向会话阅读，不注入被测模型）

- 两张卡由方向会话本机启动，`executor: strong`，不交默认弱模型 build 三审链。被测模型同为 GPT-6.1 sol、Codex CLI、xhigh；若不可用整批 blocked，不悄悄换模型。记录实际模型标识、客户端、有效设置及能核到的返回元数据；只有请求别名时明说，配对可比性降级。
- 每题两份固定基线、各自独立浅检出的目标仓库（不共享 Git 对象）、新非交互进程和空会话。两个执行者互不可见；各自 cwd 与可读范围仅该目标检出和必要运行工具，不向模型挂载 a1dbv、旧补丁、协议或另一臂。记录实际可读边界和越界工具访问；无法建立隔离则 blocked，不能仅用“新会话”声称隔离；不继承本轮设计、旧模型答案、此仓实验、结果或评审。两臂同项目指令、依赖、工具、权限、联网范围和运行反馈能力。现行组也可以截图、看图、连续工作和自主选工具，不额外强制三审/拆卡。
- 第一题短任务先跑，第二题现行先跑；不并发争用真实 GPU。每臂最多 2 小时，连续执行至交付或时限，不人为插入步骤审批；方向会话不提示修法。记录中断/限流/人工帮助，偏离不掩盖、不静默重跑。原调用未终态不重启。
- 每题正式启动前，方向会话在相同依赖/机器验证原 issue 于固定 SHA 可复现，冻结启动命令、环境版本、验收输入与预期；两臂克隆该环境。无法复现或装依赖失败则该题 blocked，不换题、不计方法失败。预检不试解法，设置成本另计。
- Excalidraw 必须从真实应用导入并查看截图；两组都可用同一个本机真 GPU 截图工具。Click 必须执行真实 CLI 并读取输出，不能用测试模拟代替。执行中是否自主观察、次数及发现的问题从实际产物记录。
- 模型只接收 `inputs/<题>/short.txt` 或 `current.txt` 对应全文，以及预检后冻结的同一 `RUN-ENV.txt`（只含运行事实、不含解法/标签）；评审断言、另一臂和方法标签不提供。现行臂使用 [冻结原提示](baseline-prompt.txt)，来源 `docs/15-task-playbooks.md §2` 于 a1dbv `9a87c1aca9a08814380d4afedf506149833e9a2f`，四份已填入共同事实的实际提示已冻结；不现场增删步骤。项目指令在两臂一致保留。
- 每臂计从完整提示被接收至停止的墙钟、模型等待/工具/人工介入时间（不可得记未知），输入/输出/缓存 token、实际计费和计价来源。订阅无单次账单记未知，不按 demo 的约 2.3 美元外推；估算单列、保留费率日期。设置、评审、返工成本单列，并给端到端总投入。
