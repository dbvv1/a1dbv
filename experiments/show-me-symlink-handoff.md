## symlink 补丁接收：先分清“链接文本”与“链接目标”

按下面的边界接收补丁：扫描链接文本；链接父目录直接报错；allowlist 不能借链接变成配置。
位置缩写：S = scripts/check_public.py；T = tests/test_check_public.py。行号均指本次补丁快照。

```diff
 scan_files
   load_allow
-    是普通文件就载入
+    无链接父目录、非原生链接、且 Git 索引非 120000 的普通文件才载入
   for path in tracked_files
-    非普通文件 / 原生链接 / allowlist -> 跳过
+    父目录含链接 -> symlink-parent finding；不读文件、不计 checked_files
+    本身是链接 -> os.readlink 原样文本；悬空链接和目录链接也扫描
     普通文件 -> read_text；core.symlinks=false 的普通链接占位文件沿用此路
-    allowlist 始终不扫描
+    allowlist 若是原生链接，或索引 120000 的普通占位文件 -> 扫链接文本
```

定位与回归：
- 原生链接：S102–104；T106–143。read_text 被设成一调用即失败；链接目标有敏感内容而链接文本干净时不命中，原始 `./missing//child` 保持原样。
- 链接父目录：S44–51、96–100；T195–222。替换已跟踪文件的父目录后，普通文件与 allowlist 都报 symlink-parent，CLI 返回 1；仅真正读到的文件计数。
- core.symlinks=false：S105–106；T145–158。真实 checkout-index 生成普通占位文件后照常扫描；这是保留既有普通文件分支，不是新加一套读取逻辑。
- allowlist：S54–71、102–106；T92–95、160–193。普通配置仍按“文件＋字面量”精确放行；原生链接和索引 120000 占位文件不载入，并扫描其链接文本。父目录为链接时由上一条拒绝。

验证：两文件逐字节复制到隔离目录后，定向 unittest 22/22 通过（含 7 个新增测试方法）。本例用于交接定位；代码候选未发布，完整检查仍超时。
