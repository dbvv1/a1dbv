## 这包能回答什么

**[经验：实验设计]** 比较固定任务下 A 无额外项目指令、B 短而有用的测试指令、C 与 B **逐字相同的有用内容**加固定无关文字。A→B 是添加这份短指令包的效果（内容和长度一起改变）；若要单独识别有用内容，需要额外的等长中性条件；B→C 是在保留有用内容前提下添加这份 padding 的效果，不能直接叫“所有长指令的效果”。padding 仍有语义、位置及分词影响；要推广需增加多种中性 padding 和位置对照。

此处只有一个容易饱和的区间归并 bug。它用于验证量尺、发现“已有测试全绿但修复错误”，**不能估计真实项目效率、长程恢复可靠性或历史 E1–E3 的可复现性**。适合先检查评估流程；不适合拿一次通过宣传模型或工作流收益。

## 文件边界

- `agent-input/baseline/`：精确的故意缺陷源代码和 4 个现有测试，每轮从这里新复制
- `agent-input/task.md`：所有条件相同的症状提示及行为契约；没有参考修复
- `conditions/neutral.md`：0 字节；`short.md`：测试命令与回归测试约定；`padded.md`：短版原文 + 80 行无关档案文字
- `evaluator/`：独立维护的固定验收、参考 patch、自检；**不发给被测 agent**
- `PROTOCOL.md`：运行前冻结的设计、计费口径与分析边界
- `results/`：空原始记录模板、JSON Schema、离线验证记录；没有模型实测数据
- `manifest.json`：固定输入及评估文件的 SHA-256；修改后应更换实验版本，不静默替换

**[经验：安全边界]** 目录分开不是权限隔离。同一文件系统上的 agent 可能读到 evaluator、参考答案、其他条件或上级仓库指令；这会污染实验。真实运行只将选定输入复制到独立的受限环境，并在 agent 停止后将候选源码交给可信评估环境。禁止把整个知识库当作被测项目挂载。`python -I` 只是降低 Python 环境污染，**不是沙箱**；评分会执行候选 Python，不能在有凭据或私人文件的环境里执行不可信产物。这里没有实现容器、网络封禁、资源沙箱或抗恶意作弊。它是可信、合作式夹具，不是对抗式安全裁判；任意候选代码可通过 os._exit、猴子补丁等影响同进程检查，不能把通过当成抗作弊证明。

## 离线复现（仓库根目录，Python 3.11+）

```bash
python3 experiments/workflow-ablation/evaluator/selftest.py
python3 experiments/workflow-ablation/evaluator/grade.py experiments/workflow-ablation/agent-input/baseline
```

第二条命令**预期退出 1**：public 4 个测试通过，held_out 套件（7 个测试方法）未通过；这证明 false-green 基线被识别，而不是安装故障。第一条命令预期退出 0：在临时副本精确应用参考 patch，固定两套检查全过；原始缺陷源代码保持不变。具体记录见 [离线验证](results/offline-verification.md)。

评估一个已完成的候选目录：

```bash
python3 experiments/workflow-ablation/evaluator/grade.py /path/to/candidate --timeout 10
```

候选目录必须含 `intervals.py`。评分始终从 evaluator 侧加载固定 public 测试，候选改弱自己的测试不能改变它。held-out 覆盖嵌套、后续相邻归并、负数/重复/同起点、输入不变/迭代器、反向区间异常、超大端点，以及小域 3,616 个有序输入组合的独立集合 oracle。测试方法数不是独立任务数。没有结果、零测试、skipped、语法错误、超时都不能算成功。

## 真实模型试验怎么接入

本包不包含 CLI/API runner，不调用模型、不安装包、不读取账号配置。运行前先完成 [预注册](PROTOCOL.md)，并自行确认调用和费用授权。

1. 新建隔离环境，只复制 `agent-input/baseline/` **内容**为项目根；确认没有继承用户级/父级指令、记忆、技能或先前会话。系统默认提示无法移除时完整记录版本、保持各组一致
2. 将 `agent-input/task.md` 与当轮 `conditions/{neutral,short,padded}.md` 直接拼接，作为唯一用户提示；不额外创建 AGENTS.md/CLAUDE.md。条件是显式提示内容，**不测自动发现/加载指令文件**
3. 保留提示、版本、工具设置、实际执行命令、完整公开可记录轨迹和最终 diff；不记录隐藏思维链、密钥或私人配置
4. agent 停止后冻结候选哈希，在 evaluator 独立环境评分。保存命令、退出码和评分 JSON；debug 时可直接运行 `evaluator/checks.py <candidate> held_out` 获取失败详情。不要把 held-out 失败反馈给同一轮 agent 再修
5. 独立审查新测试：在最终修复上通过，在新的原始缺陷副本上失败，并确认失败为目标行为断言，而非导入/环境失败。记录新增测试数量、准确命令与退出码。不要在原工作树上 stash/revert
6. 每轮完整填一条原始记录，包括失败、超时、超预算与人工介入；保留原始输出。模板里的 null 表示未测量，不能当作 0

**已知限制**：评分没有自动验证新测试质量、编辑范围或过程日志，需要独立审查；没有检测所有作弊；超时只终止当前检查进程，不能替代进程树/内存/网络资源沙箱；有限 oracle 不证明任意整数输入上的数学正确性。参考 patch 只证明本任务有解，不是唯一可接受实现。公开夹具容易被训练或提示污染，正式效果评估应另建从真实失败采样的未见任务。
