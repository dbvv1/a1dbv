## 2. 判定，不报综合总分

逐题分别判：决定是否可执行、关键条件是否正确、撤回点是否具体。每维用“满足／部分／不满足／不可判”，不奖励页面措辞、特定产品名字或更长答案。只有三维均满足且没有违反题目硬约束，才记“答对”；允许多个正确方案。

按页报告三题的配对结果：两组都对、仅读页对、仅无文档对、都不对，以及错因和判定分歧。不给文档也答对比例为该页有效无文档答案中答对的比例（25是允许同额联网的基线，不解释成纯模型常识），同时列有效样本数／计划3题；无效样本不静默丢弃。若两组有效题目不同，不直接相减为增量。三题只够发现问题，不推出稳定效应或全站收益。25另报实际发现目标是否达成；诚实暂缓可能是正确决定，但不算找到了候选。B25-3在首次搜索前冻结初始候选／已知来源，只说明本轮名单之外，不证明模型此前未见。

先由不知道组别的核查者按冻结要点判断，保留合理异议，再揭示组别；文本可能暴露读页条件，故只称标签隐藏，不称双盲。错因按事实／条件误判、无明确选择、忽略真实接收、指标混淆、无撤回、过量流程、恢复状态误判等记录。原始回答与失败本地保留，公开只交必要摘要。

读页也错或无文档已答对的题，回到对应页面检查增量和表达；前者可能是建议问题、未吸取或题目歧义，不能只凭一次错答就改正文。看到答案后不改本轮要点；修题另建版本并重新冻结，旧结果不合并。
