# P79 审题与判定要点（不得提供给答题者）

状态：v1已独审冻结，任何作答后的判据修改须另版本。


以下是可接受答案的约束，不是要求逐字复述的唯一解。每题分开判 D（可执行决定）、K（关键条件与核查）、R（具体撤回观察）：满足／部分／不满足／不可判。D/K/R均满足且没有违反题文硬约束才记答对，不合计总分。下面逐题要点是必要语义而非术语清单；合理替代可以满足同一判断目的，不能因未复述全部例子扣错。凭页面术语、型号名、措辞相似不加分；只说“小步迭代、加测试、注意安全”不足以证明满足本题。严重错误是直接违反题文硬约束、编造已发生的执行或关键事实，需指出具体文本。

错因分类：E1 无决定；E2 混淆层次/机制；E3 指标或计费口径错误；E4 忽视原有行为/真实接收；E5 把自报/历史个案泛化为事实；E6 不可执行或无撤回；E7 过量流程无对应缺口；E8 忽略迁移与恢复状态。可多选，另记合理异议。

### A00-1
必要判据（三项；可用等价实现满足）：先给可执行的扩大／不扩大安排；比较完整交付中的人审或返工而非只看生成速度；给质量或接管退步时的收缩条件。
参考推理与核查示例（不要求逐项复述）：
D：先调整可理解和可验收的交付单位或审查支持，再有条件扩大自动化，而非仅移除审查。K：区分生成快和端到端净收益，检查人工理解、返工与维护回归。R：扩大后不可解释变更/返工增加则缩回，若完整周期质量不退且总投入降低则可扩大。错因 E3/E4/E6。允许高自主方案，但须给出能替代现有审查发现问题的证据和可接管性。
### A00-2
必要判据（三项；可用等价实现满足）：给重新试用或有依据暂缓的选择；核新代际在本项目修改及旧行为上的表现；给推广、撤回或重开条件。
参考推理与核查示例（不要求逐项复述）：
D：可在代表性、可回退的业务修改上重新比较新工具与原方案；不因旧失败永久否定，也不因新演示直接全量恢复。K：模型/入口代际与本项目任务匹配，至少覆盖本次与后续修改的旧行为。R：首轮好看但下一改复发/人工投入恶化则不推广。错因 E5/E4/E6。也接受因期限、迁移成本或现有收益有限而暂不试用，但须给出重启条件，不强制重新比较。
### A00-3
必要判据（三项；可用等价实现满足）：明确首批交付范围／是否暂缓；核关键路径可维护或故障恢复；给不能接管或真实路径失败时的收缩条件。
参考推理与核查示例（不要求逐项复述）：
D：限定能验证、维护和恢复的交付范围；优先可接管性而非新增功能。K：有人能解释关键路径并在服务不可用时诊断/回滚，演示与持久化、故障路径、真实使用区别。R：关键问题无法独立恢复或真实路径不达标则延期/缩范围。错因 E4/E6。可以交付有限试用，也可暂缓，不能用所有代码人工重写作为唯一正确解。
### A01-1
必要判据（三项；可用等价实现满足）：明确保留、比较或分工入口；核此次任务的环境／验收与完整投入；给新方案不达标时的撤回点。
参考推理与核查示例（不要求逐项复述）：
D：保持现有可用入口作基线，按本次质量/依赖挑一个小而完整的比较；可按任务拆角色但不强制两工具并用。K：同题输入、迁移验收、环境工具与实际返回结果，包含人审和返工；快出初版不足以决定。R：新入口无法完成迁移或端到端投入更高则回原入口。错因 E2/E3/E6。
### A01-2
必要判据（三项；可用等价实现满足）：保留不可迁移的本地验收并明确分工；核云端实际资源和返回产物；给迁移无法验收或交接不值时的撤回。
参考推理与核查示例（不要求逐项复述）：
D：保留本地专属验收，可把能独立完成且环境齐全的部分放云端；全留本地亦可。K：云端仓库/依赖/网络和本地设备不可假设继承，明确中间产物及谁验收。R：云端无法交回可本地验证的产物或交接成本抵消收益时退回。错因 E2/E4/E8。不以“云端不安全”泛论代替依赖判断。
### A01-3
必要判据（三项；可用等价实现满足）：试用针对会话管理而非假定同模型能力提升；核工作隔离和恢复／验证；给管理收益不足或破坏现流程时的撤回。
参考推理与核查示例（不要求逐项复述）：
D：先试会话/工作区管理这一需求，而非把新界面等同更强编码能力。K：保留同模型与任务，核工作区隔离、依赖、未提交改动/恢复、实际测试入口与操作成本；worktree、独立clone或容器等正确实现均可。R：管理负担未减少，或迁移破坏现有验证/恢复，则留原 CLI；管理确有收益可迁。错因 E2/E7/E8。
### A02-1
必要判据（三项；可用等价实现满足）：根据现有产物决定续作或暂停；定位未推进及上下文／循环等可核因素而不猜扣额公式；给预算或无进展终止条件。
参考推理与核查示例（不要求逐项复述）：
D：先对账已完成/未完成再续做，定位反复处理大上下文或循环与真正难点；允许更小任务、合适档位或暂停。K：记录有效产物、重复工作、缓存/非缓存、人工时间、订阅窗口；不能凭缓存计数确定扣费公式。R：续做依然不推进或预算耗尽则停并改路；不能无条件补额度。错因 E3/E8/E6。
### A02-2
必要判据（三项；可用等价实现满足）：不接受无依据现金损失数；区分实际模型、累计计数和订阅／API支出及因果未知；给配置调整或恢复的依据。
参考推理与核查示例（不要求逐项复述）：
D：撤回未经支持的现金损失数，分报切换期/修复期客户端消耗与观察到的额度变化；必要时恢复经过验证的配置。K：核实际模型、计数是否累计/包含缓存或推理子集、订阅/额外 credits/API 范围；因果归因另需对照。R：恢复后完整任务仍无收益则重新选型，不以价格更高推定更好。错因 E3/E5。计算缺数据时明确不可计算即可，不要求外部查当日价表。
### A02-3
必要判据（三项；可用等价实现满足）：不凭通用榜单或单价直接替换；以DSL业务语义和完整投入对照；给必要行为或总成本退步的撤回点。
参考推理与核查示例（不要求逐项复述）：
D：用真实代表性 DSL 任务小样本对照后决定全替/分流/不替。K：语法之外验证语义、罕见约束、失败返工和人工审核，比较完整有效产出成本而非 token 单价；冻结必要行为。R：语义错误或修复总投入越界则回旧模型，可对容易且达标的子任务单独采用。错因 E3/E4/E5。
### A03-1
必要判据（三项；可用等价实现满足）：明确保存原意及必要视觉约束的做法；接续后核产物是否仍符合原效果；给继续丢意图或维护代价不值时的改法。
参考推理与核查示例（不要求逐项复述）：
D：在开始前保留此次意图、不可变视觉概念及必要证据；可新会话/显式精简交接/主动核对，不能只增加总文档。K：小代码改动也受长会话影响，读取指令不代表保留任务含义；接续时对照原始约束和当前产物。R：恢复后仍换概念或信息维护成本过高则调整边界，回退错误改动。错因 E2/E4/E8。
### A03-2
必要判据（三项；可用等价实现满足）：不把停用等同占用降低；控制变量核实际上下文和能力影响；给不降占用或任务变差时的撤回。
参考推理与核查示例（不要求逐项复述）：
D：先核目标版本中停用实际作用及上下文构成，再选卸载/移除分发项/按需加载或保持现状。K：应区分禁止调用与减少上下文；能控制变量核实际占用和任务表现即可，目录／描述／正文只是可调查的解释，不要求说出三级术语。R：占用不降/需要的能力丢失/任务变差则撤回该配置。错因 E2/E5/E6。不得把原帖历史缺陷当现在必然。
### A03-3
必要判据（三项；可用等价实现满足）：区分必要项目约束与临时状态并按任务提供；用实际行为核旧bug而非只加长规则；给遗漏或负担恶化时的调整。
参考推理与核查示例（不要求逐项复述）：
D：给出任务范围相关入口、近期约定与已修 bug 的可核事实，常驻规则与临时任务状态分开；允许保留现有文档但按需取用。K：要区分检索到、理解/遵从与行为回归；保旧 bug 的重现/检查，避免靠更长规则弥补验证空缺。R：遗漏仍在或维护/上下文负担升高无收益就调整，不能无限加规则。错因 E2/E7/E4。
### A05-1
必要判据（三项；可用等价实现满足）：先区分可见／触发与真实执行，不无依据全重装；用目标宿主最小复现或显式与自然调用对照；给失效时用已验证路径的条件。
参考推理与核查示例（不要求逐项复述）：
D：最小复现区分安装/发现/加载/触发/执行；查实际调用与目标版本，而非立刻重写或重装一切。K：管理界面、模型自述、子任务可见性均不是完整执行证据；比较显式调用与自然触发。R：不能稳定触发则暂用已验证路径，确认为文案问题才改触发描述；无额外效果不继续堆提示。错因 E2/E5/E7。
### A05-2
必要判据（三项；可用等价实现满足）：不接收只有说明的完成声明；核目标工具调用和真实返回，允许直接工具完成当前任务；给恢复Skill所需执行证据或停用点。
参考推理与核查示例（不要求逐项复述）：
D：不接收“完成”声明，当前任务可以走已验证的直接调用；隔离 Skill 调用路径问题。K：检查目标工具是否真被调用、返回值/产物、宿主和分叉路径；直接调用成功不能证明分叉有同样能力或身份。R：恢复前要求可核的真实查询结果；若主张修复特定失败分支，补对应复现而非无条件加负例；仍只解释则停用包装，不泛化所有 Skill 无效。错因 E2/E4/E5。
### A05-3
必要判据（三项；可用等价实现满足）：不把未预加载等同不可访问；在目标子Agent核实际可读／可执行及允许范围；给不符合迁移要求时的调整或停止。
参考推理与核查示例（不要求逐项复述）：
D：在目标子 Agent/宿主上单独验证加载、发现、执行与权限，不把未预加载当不可访问。K：分别检查启动内容、文件/工具可访问性、实际行为与允许范围；目标能力所需信息要显式交代。R：权限或能力不符合就调整分工/边界或停止迁移。错因 E2/E5/E8。此题含权限但主考迁移契约，不奖励泛泛安全口号。
### A07-1
必要判据（三项；可用等价实现满足）：明确明日完整路径优先；区分未决意图和实现错误并保旧行为验证；给修补继续破坏或最低交付失败的撤回。
参考推理与核查示例（不要求逐项复述）：
D：收敛到明日那条完整路径，分清未决产品条件与实现错误，保存已修回归，受控修复而非继续扩全规格。K：新功能、旧行为、真实路径均有可观察反馈；需要澄清的假设先解决。R：继续修补破坏旧行为或无法完成最低路径时回到已验证版本/缩范围。错因 E4/E6/E7。
### A07-2
必要判据（三项；可用等价实现满足）：按依赖与可审查边界选拆分或原子变更；核完整交付及理解／整合代价；给新方式无收益或返工增加的撤回。
参考推理与核查示例（不要求逐项复述）：
D：可按可理解/可运行边界拆分，也可保跨模块原子变更并分阶段解释验证；不是机械每文件一任务。K：依赖和审查理解成本、整合点、旧行为；比较完整交付加人审时间，不以变更大小单独判断。R：拆分引发反复返工/整合开销，或审查不改善，则改划分/缩流程。错因 E3/E7/E4。
### A07-3
必要判据（三项；可用等价实现满足）：拒绝只以绿测试定义无限循环；核交接前后意图和实际视觉结果；给偏离效果或重复无进展的终止。
参考推理与核查示例（不要求逐项复述）：
D：不采用仅测试绿的无限循环；保原意与实际视觉反馈后才允许有界迭代。K：自动检查通过与目标效果不同，交接前后约束核对、视觉验证和旧行为检查各有角色。R：循环只优化代理指标/偏离效果/重复无进展时停止，回退不符合目标的方案。错因 E4/E7/E8。



判定统一使用D/K/R及题文硬约束，不合计总分；以下为可接受方向与反例，不要求逐字匹配。

### B08-1
必要判据（三项；允许等价实现）：明确可执行合入安排；核共享契约/消费者与组合后验收；给依赖或整合代价不符时的改排条件。
参考方向（下列核查为示例，不要求每项出现）：
来源R1（并行冲突处理）+R0；三个PR/明天/接口场景为改编。
要点：先查依赖、预期合入版本、接口消费者和谁负责整合；可并行读/预演，也可独立工作树写，但共同契约变化需有次序或明确重基准；在组合后的真实目标上跑回归，不能拼接三个分支绿灯作整体证明。发现基线不一致、重复修改或整合成本盖过收益则收敛/重排。允许有明确隔离与整合证据时并行写，不强制“读并行写串行”。
错因：分支通过替代整合；共享契约漏项；并行教条。

### B08-2
必要判据（三项；允许等价实现）：区分主会话可读和执行者实际能力；沿已有允许路径继续必要工作；给重新委派需见的真实访问及产物证据。
参考方向（下列核查为示例，不要求每项出现）：
来源R1；两错误、权限限制为改编。
要点：区分界面配置与执行者实际可访问性，记录路径/身份/工具失败；先用可用的主会话完成必要检查或改为只读委派，不无依据扩大权限；如保留委派，先验证目标执行者对正确工作树的最小读写/测试能力及交付入口。无法访问必需资源或交付成本过高则撤回。权限拒绝不能当网络瞬断无限重试。
错因：标称权限当实际能力；越权绕过；工具失败冒充任务失败。

### B08-3
必要判据（三项；允许等价实现）：先恢复正确工作身份并找回可核产物；不沿用陈旧接口计划或测试声明；给基准/产物不明时的停止条件。
参考方向（下列核查为示例，不要求每项出现）：
来源R2+R0；未派发计划是改编。
要点：暂停依赖cwd的写入，重新核对主仓路径/分支/head及结果所在分支/commit；取回可验证产物，不因临时目录消失就认定代码消失，也不盲用测试声明；对照整合后接口重算未执行任务，验证组合行为才续派。无法定位产物或基准则保留未知、停止进一步写。仅修pwd而不更新计划不够。
错因：路径即身份；陈旧计划继续；结果声明当产物。

### B09-1
必要判据（三项；允许等价实现）：按实质风险选择继续或接收，不求零评论；固定当前差异并核已修问题；给新实质风险或关键验收失败的再审/延期条件。
参考方向（下列核查为示例，不要求每项出现）：
来源R4（后续修复与维护质量的真实读者任务）；三轮具体发现/预算改编。R11仅为相似问题背景，不计入正式来源。
要点：关闭真实数据丢失与取消语义问题，以当前diff/commit及复现检查为准；对修复影响范围复审而非无限全量循环；命名可另记，不因零发现次数决定完成；覆盖关键用户路径、已知高风险和必要人工语义决定才接收。新实质缺陷或检查无效则续审/延期，重复无新增高价值发现且主要风险已关闭则停止。不同模型可选而非必要。
错因：零发现幻觉；循环次数即质量；修复未复验；把所有发现当同等风险。

### B09-2
