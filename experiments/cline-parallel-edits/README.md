# Cline：同文件并发编辑，核磁盘和业务结果

**同一文件的不同区段，仍按一个写入面接收。** Cline 基线的 `editor`／`apply_patch` 并发调用都报成功，却在实际磁盘上丢掉一项修改；工具回复不能替代整合后的项目测试。
**🧪 既有 #15419 候选在本次单进程消费者中修正了丢改动。** 它把两类工具放进共享路径队列，适合接收这一窄修；多 Agent／多进程仍沿用[长程路线的单写者分工](../../docs/decisions/long-tasks.md)。
**尚未合入，不更换工具默认。** 这里接收编译后 SDK 的真实文件编辑能力，不是 Cline 模型、CLI、Hub 或桌面全链路验收。

## 真实输入和观察

合成支付模块有两处独立错误：`net` 把折扣加上去，`tax` 用了旧税率。实际输入为：

```js
exports.net = (gross, discount) => gross + discount;
exports.tax = (net) => net * 0.10;
```

两个工具分别改为 `gross - discount` 和 `net * 0.20`。验收另起真实 Node 进程，从磁盘导入模块，断言 `net(100, 10) = 90`、`tax(90) = 18`、总价 `108`，并核 Git diff；没有模拟文件系统、队列、读写屏障或调度延迟。

| 同文件并发输入 | 每版样本 | 基线业务通过 | 候选业务通过 |
|---|---:|---:|---:|
| 同一 editor 实例 | 5 | 0 | 5 |
| 不同 editor 实例 | 5 | 0 | 5 |
| 同一 apply_patch 实例 | 5 | 0 | 5 |
| 不同 apply_patch 实例 | 5 | 0 | 5 |
| editor 与 apply_patch 混用 | 5 | 0 | 5 |

基线这 25 次均收到两条成功回复，但磁盘只保留一项修改：9 次总价为 `99`，16 次为 `132`。候选 25 次均保留两项并得到 `108`。这是本机自然交错的观察，不是所有机器的必现概率或速度指标。

两版另各有 5 个控制全部通过：editor／patch 顺序调用；缺失文本／hunk 拒绝后，同队列有效编辑及下一次修正仍可完成；两个不同文件的编辑经跨文件总价消费。错误调用保留为 rejected，不把外层观察脚本 exit 0 当每个业务测试通过。业务验收总计基线 **5/30**、候选 **30/30**。

## 采用边界

- 队列只协调**同一已加载 SDK 运行时中的规范化路径**，不覆盖其他进程、重复包实例、外部编辑器，也未合并符号链接／硬链接身份；默认 `restrictToCwd` 也不是文件系统沙箱。
- 多文件 patch 仍逐文件落盘，失败可能部分生效；队列等待计入外层工具超时，超时不取消底层编辑。本次没有验证事务、超时取消或吞吐收益。
- 本次独立消费者没有测相反路径顺序、多文件 move、路径别名、Windows／macOS；部分相关组合仅有作者回归测试。
