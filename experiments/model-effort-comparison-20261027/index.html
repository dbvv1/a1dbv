04 / READ THE FINE PRINT

看图之前，分清这四件事

AIndex 不是百分比，也不是纯编码

AA Intelligence Index v4.3.2 是综合评测指数，不能读成“答对了多少百分比”。图中综合费用使用对应的加权 API 估算美元 / 题；它与 TB4 每题费用不属于同一个分母。外部来源可能已换用新版 Index；综合分与综合每题费用须在同一版本内比较，不与本页 v4.3.2 快照混用。

AA Intelligence Index 方法 ↗

BTB4：统一框架，不是等 token 预算

AA 的 Terminal-Bench 4 使用 mini-swe-agent：66 题、每题 3 次、按 pass@1 统计，最多 500 步；遵循上游时间 / 资源约束，保留完整轨迹、不压缩上下文。统一框架不代表每个配置用了同样多 token。

AA 基准测试说明 ↗

C费用是估算，不是实扣账单

AA 按评测产生的输入、缓存命中 / 写入、reasoning 与答案 token，结合观察时的当前定价与缓存测量估算 API 费用；不是服务商实扣账单，也不包含沙箱、主机、人审或总工程费用。成绩差异不能单独证明真实项目里的投入产出比。

AA 费用与评测方法 ↗

DDF 与快照的边界

Fable / Opus / Sonnet 标注 Default Fallback：安全拒答时转交推荐模型，逐题是否触发未知，因此是产品配置比较，不能保证每题都由单一基础模型完成。本页没有在你的仓库上实测；模型发布日期不是测试运行日期，AA 记录未公开精确运行时间与 API 快照 ID。
